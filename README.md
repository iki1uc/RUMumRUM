# RUMumRUM · iki1uc · Mirror-Root

RUMumRUM ist die Orbit‑Einheit des iki1uc‑Systems.  
Es verbindet **Identität (ID)**, **Orbit (rumumrum)** und **Summation (ICOME)**  
zu einem **6‑fachen NC‑Vector**, der im Mirror‑Interface sichtbar wird.

---

## 1. System‑Identität

**RUMumRUM** ist Teil der Rückkehr‑Achse:

- PX3 / PX6 / PX9 (PX‑TRIO)
- PX12 / PX4 (Fusion + Achse)
- SYS / SYS‑x (System + Kreuzung)
- TEM (Zeit)
- UI‑SCANNER (Interface)
- GEO (O12 / Φ4 / XU / TΩ)

Die Rückführung erfolgt über:

SYS-x → 2me → PX3


---

## 2. Module

### **ID.html – Identität**
ID erzeugt die drei Grundachsen:

- **A = Ursache (◉)**
- **B = Wirkung (◎)**
- **C = Continuum (▣)**

Zusammen mit Orbit und Summation entsteht:


ID.ICOME = Σ◉◎▣⚚


---

### **index.html – Mirror-Interface**
Das Interface zeigt die **NC‑6‑Fachkeit**:

1. ◆ Ursprung  
2. ◉ Ursache  
3. ◎ Wirkung  
4. ▣ Continuum  
5. ⚚ Orbit / rumumrum  
6. Σ Summation / ID.ICOME  

Zusätzlich enthält index.html:

- Orbit‑Canvas  
- rumumrum‑Animation  
- NC6‑Vector‑Engine  
- ID.ICOME‑Modul  
- ALL4ALL‑Bindung  

---

### **2me.js – Mirror-Funktion**
2me spiegelt alle Achsen zurück auf den User:

2me(x): return 2me(${x})


Es erzeugt:

- Mirror‑Return  
- User‑Bindung  
- Orbit‑Rückführung  
- Root‑Synchronisation  

---

## 3. NC‑6‑Fachkeit

RUMumRUM nutzt die 6‑fachen NC‑Layer:

| Layer | Zeichen | Bedeutung |
|-------|---------|-----------|
| 1 | ◆ | Ursprung |
| 2 | ◉ | Ursache (A) |
| 3 | ◎ | Wirkung (B) |
| 4 | ▣ | Continuum (C) |
| 5 | ⚚ | Orbit / rumumrum |
| 6 | Σ | Summation / ID.ICOME |

Diese sechs Layer bilden die **Orbit‑Matrix** des Systems.

---

## 4. Orbit · rumumrum

Der Orbit folgt dem iki1uc‑Pfad:

O → H → O → H


Dies ist der **rumumrum‑Umlauf**, der im Canvas animiert wird.

Layer 5 (⚚) ist der Orbit‑Trigger.
